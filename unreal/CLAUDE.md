# Работа с Unreal Editor через MCP

Редактор доступен как MCP-сервер `unreal-mcp` (http://127.0.0.1:8000/mcp, см. `.mcp.json`
в корне). Он слушает только loopback, поэтому работает лишь из Claude Code,
запущенного на той же машине, что и редактор.

Экономия токенов:
- Миры, корабль и небо строит код (C++, PCG-графы, скрипты редактора) из этого репозитория.
  Через MCP только запускаем, проверяем и подкручиваем параметры. Акторы по одному не расставляем.
- Не выгружай всю сцену целиком: запрашивай акторы по классу, метке или имени.
- Скриншоты вьюпорта только по просьбе или для финальной проверки: каждый стоит заметно дороже текста.
- Данные (каталоги звёзд и экзопланет) лежат в `unreal/Data/*.csv`: импортируй их как DataTable,
  не пересказывай содержимое в разговоре.
- Логика переносится из `universe/*.ts`. Сиды и хеши (`mulberry32`, `hash32`) те же,
  поэтому одинаковые сиды дают одинаковые миры.
