# University — процедурная вселенная

Вселенная в браузере на three.js: от космической паутины до поверхности планеты.
Галактики и планетные системы выводятся из множества Мандельброта, орбиты —
из законов Кеплера, небо — из рассеяния Рэлея и Ми.

## Что внутри

- **Уровни:** космическая паутина → галактика → звёздная система (настоящая
  Солнечная система на сегодняшнюю дату или сгенерированная) → поверхность
  планеты; чёрная дыра с трассировкой лучей.
- **Полёт:** корабль от третьего лица, обзор движением мыши, автопилот,
  порталы в другие системы и галактики.
- **Бой и миссии:** враги с HP, волны, миссии по цепочке.
- **Существа:** десять видов, с ними можно поговорить (T). Реплики пишет ИИ
  (OpenRouter, Groq или Gemini, ключ вводится в окне разговора и хранится
  только в браузере); без ключа — встроенный сценарий.

## Управление

Движение мыши — обзор и поворот · WASD, Q/E — тяга · Shift — форсаж ·
Пробел/ЛКМ — огонь · T — поговорить · L — посадка · M — миссии ·
V — вид · C/ПКМ — оглядеться · двойной клик — захватить мышь.

## Разработка

```bash
npm install
npm run dev        # http://localhost:3000
npm test           # физика, миссии, диалоги
npm run typecheck
npm run build      # статическая сборка в dist/
```

## Публикация

**GitHub Pages** (бесплатно, открыто всем): при каждом пуше в `main` workflow
`.github/workflows/pages.yml` собирает сайт и публикует его на
https://tatyanawaves.github.io/university/. Один раз нужно включить Pages:
Settings → Pages → Source: **GitHub Actions**.

### Vercel

Импортируйте репозиторий в Vercel (Add New → Project → `tatyanawaves/university`)
и назовите проект `university`. Vercel сам определит Vite: команда сборки
`npm run build`, каталог `dist`.
